# Game Introduction

玩家控制一個"小朋友"角色，小朋友需要往左右跑離開平台以往下掉，避開最上方的尖刺，下面會不斷出現不同的樓梯平台，其中也可能有特殊功能或陷阱，或是帶著金幣，吃到一定個數金幣以通關，目前預計做十關

介紹影片：https://youtu.be/fwBsopVz1ik?si=shj7Wf3_4hwIS16r&t=174
